01 / Problem

Bird ID is a comparison problem.

Bird identification improves through repeated comparison. vBird turns it into a swipe game — two photos, same species or not — with a casual mode for speed and a learning mode that schedules reps with FSRS spaced repetition.

Keeping the loop quick is the easy half. The hard half is the data: matching runs on pre-labeled pairs and SQL, not runtime ML, so source quality, image provenance, and species facts all have to line up before a card ever ships.

02 / Approach

Train the eye, audit the data.

① Two loops

A casual mode for quick swipe reps and a learning mode that paces review with an FSRS spaced-repetition schedule.

② Backend as curriculum

Supabase holds users, learning state, species data, images, and release evidence in one product system with row-level security.

③ AI offline, with receipts

Gemini extracts and shapes content in a build-time pipeline — never at runtime — and every fact keeps its source trail.

03 / System

The learning loop has a data spine.

The app reads pre-labeled pairs from Supabase (images served via Cloudflare) while a separate offline pipeline prepares species metadata and audit-friendly assets.
