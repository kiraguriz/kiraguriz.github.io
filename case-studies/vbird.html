Case study

vBird

A bird identification training app for North American birders, with game-like matching, learning schedules, and a data generation pipeline.

Problem

Bird identification improves through repeated comparison. vBird turns species recognition into a swipe-based training loop backed by curated image and species metadata.

Technical work

  • Expo and TypeScript mobile app with casual and learning modes.
  • Supabase backend using Postgres, Auth, Storage, Edge Functions, migrations, and row-level security.
  • Python data pipeline from eBird, Wikidata, Wikipedia, iNaturalist, and Gemini-assisted extraction.
  • Release gates for external evidence, audit logs, legal pages, store listing, screenshots, and privacy checks.

What it shows

This project shows how I think about AI and data as a system: generation, validation, auditability, storage, and product release all have to line up.
