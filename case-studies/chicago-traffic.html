01 / THE PROBLEM

A dataset needs a question before it needs a chart.

The source database combines intersections, camera locations, and daily violation counts. To compare locations or years, the tool needs consistent joins, grouping, and date handling before the results can be interpreted.

What I owned

I built a console tool that translates questions about intersections, cameras, years, and streets into parameterized SQL queries, formatted results, and optional plots.

BUILT WITHPython / SQL / SQLite / Matplotlib

02 / KEY DECISIONS

The choices
behind the work.

Implementation is a series of decisions. These are the ones that shape this project.

01

Let SQL do the aggregation.

Joins, grouped totals, percentages, and date grouping run in SQLite. Python receives the result set for formatting and plotting.

THE TRADEOFFThis keeps query logic explicit and avoids duplicating aggregation in application loops.

02

Bind user input as parameters.

Intersection, street, year, and camera input are passed as bound parameters. Queries can support search patterns without constructing SQL from raw input.

THE TRADEOFFThe query and its parameter semantics still need to be understandable to the person using the console.

03

Give the same result several useful forms.

The tool offers ranked tables, time-series plots, and camera locations over a Chicago basemap. The presentation follows the question.

THE TRADEOFFA geographic background gives context, but it is not an analysis result until the actual data is plotted.

03 / SHOW THE WORK

What you can
inspect.

The portfolio includes the Chicago basemap used by the plotting flow and an example parameterized aggregation query.

Inspect the example SQL query
SELECT Intersections.Intersection,
       SUM(RedViolations.Num_Violations) AS total
FROM Intersections
JOIN RedCameras
  ON Intersections.Intersection_ID = RedCameras.Intersection_ID
JOIN RedViolations
  ON RedCameras.Camera_ID = RedViolations.Camera_ID
WHERE strftime('%Y', RedViolations.Violation_Date) = ?
GROUP BY Intersections.Intersection
ORDER BY total DESC;

Scope of this evidence

The map shown is the base layer, not a rendered violations analysis. No performance benchmark or current public-data refresh is claimed.

WHAT I TAKE FORWARD

Choose the question first. Keep its meaning intact through the query, the returned rows, and the final chart.
