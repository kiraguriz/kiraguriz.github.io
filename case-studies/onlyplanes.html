Case study

OnlyPlanes

Aviation mobile product for real-time flight tracking, plane spotting workflows, and community features.

Problem

Plane spotting needs a mobile-first workflow that joins live aircraft positions, searchable flight details, spotting places, and lightweight community context.

Technical work

  • React Native and Expo app with map-first interaction patterns for live aircraft tracking.
  • Fastify and TypeScript backend with OpenSky integration, in-memory flight cache, and shared API contracts.
  • Mobile route, marker, fallback, and tracker state work that needed careful UX and performance handling.
  • Release-hardening work around health endpoints, production config, route trust, analytics, and runtime review.

What it shows

OnlyPlanes is the best example of product engineering under real constraints: live data, maps, mobile interaction details, backend contracts, tests, and operational readiness.
