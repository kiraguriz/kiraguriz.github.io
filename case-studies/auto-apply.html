Case study

Auto-Apply / AI Job Agent

A local-first workflow for job discovery, application preparation, browser traces, and review-first automation.

discover.jobs() rank.fit(profile) draft.cover_letter() run.browser_trace() stop_before_submit()

Problem

Job application workflows are repetitive, but fully automated submission is risky. The useful product boundary is preparation, evidence, and review, not blind submission.

Technical work

  • Python local backend for ATS automation, screenshots, traces, profile mapping, Q&A, cover letters, and APIs.
  • Expo React Native shell for profile UX, job discovery, run control, review, and audit surfaces.
  • Provider abstractions for deterministic mocks and local OpenAI-compatible LLM endpoints.
  • Explicit pauses for CAPTCHA, MFA, verification, bot checks, paywalls, and final submit.

What it shows

This project shows how I build AI tools with operational boundaries: useful automation, traceability, and human approval where the risk is real.
