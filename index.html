01 / About

How I got here.

I build software by following the evidence: read the current system, find the source of truth, change the smallest surface that solves the problem, then verify it with tests, device runs, or live data.

Most of my recent work sits between mobile product and operational systems: live flight tracking in OnlyPlanes, finance workflows in GroWu, location tooling in MapPulse, release work in vBird, and a paper-trading research stack where logs and account state have to agree.

I use AI heavily, but I don't want it to blur responsibility. Good tools should show their assumptions, preserve user data, ask before destructive actions, and help a person make a better decision instead of pretending to be magic.
